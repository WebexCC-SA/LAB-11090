# Lab 4: Devices and workspaces

In this lab, you will learn how to assign devices to users and create workspaces.

**1. Ricardo Filice needs a 9871 phone.**

*Management > Devices > Add device > Add a device to a user*

Assign device to Ricardo Filice

- Cisco Desk Phone: Cisco 9871
- Activation method: Activation Code
- Copy and paste the activation code into a text file for reference later

**2. The conference room needs a phone with the capability of external dialing.**

*Management > Workspaces > Add a device to a workspace*

Create a new workspace with the corresponding device and services. Devices will be added using activation code.

- Workspace name: Conference Room A
- Location: VitaCrunch
- Device: Cisco Desk Phone: Cisco 9811 – By activation code
    - You will not activate this device
- Services
    - Calling – Cisco Webex Calling
    - Disable Hot Desking Sign in
    - Common area workspace
    - Extension: 301
