# Getting Started with Your Environment

## Using This Guide

- The lab steps use numbered headings.
- Italic text is the navigation steps in Collaboration Control Hub.
- Bullet points describe tasks to complete.
- If configuration settings are not mentioned in the guide, leave them with default settings.
- At the end of each lab, stop and wait for further instructions.
- Use the navigation at the bottom of the pages to navigate to the next lab.
