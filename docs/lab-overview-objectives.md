# Lab Overview and Objectives

Enhance your cloud-based calling skills with this interactive, accelerated hands-on lab focused on Webex Calling. Over a 4-hour session, you will engage in practical exercises including configuring PSTN connections, utilizing key features, and managing call routing through Webex Control Hub. This lab provides a simulated environment to practice efficient call handling, explore mid-call functions, and understand call flow management, empowering you to optimize your organization's telephony infrastructure and communication systems.

**Lab objectives**

1. Configure Organization and Location Settings: Learn to navigate Webex Control Hub to establish foundational telephony settings, including internal dialing plans, PSTN connections, and business hour schedules for multiple office locations.
2. Manage Users and Provision Devices: Gain practical experience in creating and managing user accounts, assigning Webex Calling licenses, and provisioning hardware devices (such as Cisco 8865 IP phones) to ensure effective communication across an organization.
3. Implement Advanced Call Routing Features: Develop skills in configuring complex telephony features, including auto attendants, call queues, hunt groups, paging groups, and call park/pickup, to optimize call flow and improve organizational responsiveness.
4. Administer Shared Workspaces and User-Level Preferences: Learn to manage shared resources and flexible working environments by configuring workspaces, hot desking, and hoteling, while also enabling users to manage their own calling preferences via the User Hub.
