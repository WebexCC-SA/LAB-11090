# Lab 8: User and device settings

In this lab, you will learn to configure user features, specifically mode management and monitoring, and configure the device layout.

**1. Set Ricardo Filice to use Operating modes.**

*Management > Users > Ricardo Filice > Calling > Call Handling > Mode Management*

- Add Sales Queue

**2. Ricardo Filice needs to quickly identify, and answer calls on monitored lines to share work tasks with colleagues.**

*Management > Users > Ricardo Filice > Calling > Between-user permissions > Monitoring*

Add monitored lines to Ricardo Filice’s profile

- Users: Stefan Mauk and Eric Steele

**3. Ricardo Filice will need to use the mode management feature and monitor lines on his phone.**

*Management > Devices > Select Ricardo Filice’s Device > Device Management > Configure Layout > Custom Layout*

Change the Line Key Configuration on Ricardo Filice’s device

- Line Key Configuration
    - Order 2: Mode Management
    - Order 3: Monitored line
- Save

**4. Verify the configuration of Ricardo Filice’s MPP now shows the operating mode and monitored lines.**

*Management > Devices > Select Ricardo Filice’s Device > Device Management > Configure Layout > Custom Layout > Preview Layout*

Layout should show the following:

- Order 1: Ricardo Filice (Primary Line)
- Order 2: Sales Queue (Mode Management)
- Order 3: Stefan Mauk (Monitored Line)

**5. Activate Ricardo's 9871 phone**

- Use the activation code you saved from Lab 4 to activate the phone at your lab pod
- Verify you can see the lines configured above
